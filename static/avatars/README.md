# Built-in avatar

`pip.glb` is Pip, the avatar the toolkit falls back to when an app has none or its model
does not load (`BuiltinAvatarConfig`, served from `/avatars/pip.glb`). It is generated by
[sermas-avatar-pip](https://github.com/sermas-eu/sermas-avatar-pip) (Apache-2.0): build
it there and copy `dist/pip.glb` here.
