# Built-in background

`default.jpg` is the background an app gets when it has none (the toolkit's
`DefaultBackground` and the API's `RepositoryBackgroundDefault`, served from
`/backgrounds/default.jpg`). It is an original, procedurally drawn room, blurred like a
shallow depth of field: wall, wooden floor, a window and sofa on the right, a shelf and a
plant on the left. The blur lets it stretch to portrait without looking distorted.
